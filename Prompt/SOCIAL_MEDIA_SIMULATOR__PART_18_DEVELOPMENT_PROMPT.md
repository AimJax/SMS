# 1. WHY THIS PART, NOW

Part 17 created the LLM-Driven Event System where the world narrator (via local Ollama) proposes and executes events. The world now has emergent storytelling, but two critical gaps remain:

**Part A — Event Causality:**
Events happen and create consequences, but there's no formal trace of *why* they happened. If Kevin loses followers after a scandal, can we answer "why did Kevin lose followers?" If Sarah and Kevin broke up, can we trace the causal chain that led to the breakup?

Without causality, the world feels like a series of disconnected incidents rather than a coherent narrative.

**Part B — Offline World Simulation:**
Currently, the world only advances when the player is actively connected. If the player leaves Monday at 20:00 and returns Tuesday at 08:00, the world has been idle for 12 hours. The player misses everything that happened while they were away.

With offline simulation, the world continues running in compressed time. When the player returns, they see a "catch-up" summary of what they missed — posts, events, drama, follower changes — creating the feeling of a living world that doesn't wait for them.

Both are essential for the "persistent online world" vision.

## 8. Time Compression

The simulation tick normally runs every N seconds. For offline simulation, we compress time:

### Compression Strategy

```csharp
public class OfflineSimulationConfig
{
    public int TicksPerHour { get; set; } = 10;        // Simulate 10 ticks per hour of real time
    public int MaxTicksPerSession { get; set; } = 1000; // Cap at 1000 ticks to prevent runaway
    public int MinTicksToSimulate { get; set; } = 5;   // Minimum ticks even for short offline
}
```

For a 12-hour offline period with 10 ticks/hour:
- 12 hours × 10 ticks = 120 ticks
- Each tick processes compressed time: 12 hours / 120 ticks = 6 minutes per tick

### Compressed World Clock

```csharp
public class CompressedWorldClock : IWorldClock
{
    private DateTime _simulationTime;
    private readonly TimeSpan _tickDuration;
    
    public DateTime UtcNow => _simulationTime;
    
    public void AdvanceTick()
    {
        _simulationTime += _tickDuration;
    }
}
```

## 9. Offline NPC Simulation

When running offline simulation, NPCs continue acting:

### Aggregated NPC Actions

For performance, instead of simulating every NPC tick-by-tick:

```csharp
public async Task<AggregatedSimulationResult> SimulateOfflinePeriodAsync(
    Guid accountId, 
    TimeSpan duration)
{
    var result = new AggregatedSimulationResult();
    
    // 1. Determine which NPCs were "active" during this period
    var activeNpcs = await _npcService.GetActiveNpcsAsync();
    
    // 2. For each NPC, simulate their behavior in aggregated form
    foreach (var npc in activeNpcs)
    {
        var npcBehavior = await _npcBehaviorService.GetBehaviorProfileAsync(npc.Id);
        
        // Predict likely actions based on personality and trends
        var predictedActions = PredictNpcActions(npc, npcBehavior, duration);
        
        // Execute the predicted actions
        var actionResults = await ExecuteActionsAsync(predictedActions);
        
        // Add to result
        result.Actions.AddRange(actionResults);
    }
    
    // 3. Run event generation for this compressed period
    var events = await _eventService.GenerateEventsForPeriodAsync(duration);
    result.Events.AddRange(events);
    
    // 4. Apply all consequences
    foreach (var evt in events)
    {
        await _eventService.ApplyConsequencesAsync(evt);
    }
    
    return result;
}
```

### Prediction Model

```csharp
// Use probabilistic model based on personality
public List<NpcAction> PredictNpcActions(Npc npc, NpcBehavior behavior, TimeSpan duration)
{
    var actions = new List<NpcAction>();
    var ticks = CalculateCompressedTicks(duration);
    
    // Posts
    var postProbability = behavior.PostingFrequency / 100.0;
    var expectedPosts = ticks * postProbability * 0.1; // 10% of ticks might have posts
    for (int i = 0; i < expectedPosts; i++)
    {
        if (Random.NextDouble() < postProbability)
        {
            actions.Add(new NpcAction
            {
                Type = ActionType.CreatePost,
                AccountId = npc.Id,
                Timestamp = RandomTimeWithin(duration)
            });
        }
    }
    
    // Follows/Unfollows
    // Likes
    // Comments
    // Event Participation
    
    return actions;
}
```

## 10. Event Generation During Offline

The LLM-driven event system (Part 17) should generate fewer events during offline simulation:

### Offline Event Generation

```csharp
public async Task<List<Event>> GenerateEventsForPeriodAsync(TimeSpan duration)
{
    var events = new List<Event>();
    
    // Reduce event generation rate during offline simulation
    var eventProbability = CalculateOfflineEventProbability(duration);
    
    // Check for potential events based on world state
    var potentialEvents = await _eventService.DetectPotentialEventsAsync();
    
    foreach (var potential in potentialEvents)
    {
        if (Random.NextDouble() < eventProbability)
        {
            // Simplify event proposal (less LLM cost)
            var proposal = await _eventService.ProposeEventOfflineAsync(potential);
            if (proposal != null)
            {
                events.Add(proposal);
            }
        }
    }
    
    return events;
}
```

## 13. Offline Simulation Scheduling

The offline simulation should run:

1. **On player return** — When an authenticated request comes in and offline duration > threshold
2. **As a background job** — For players who have been offline but may return
3. **Periodically** — For commonly-active accounts to keep their feed fresh

### Background Offline Simulation

```csharp
public class OfflineSimulationBackgroundService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            // Find accounts that have been offline for > 1 hour
            var offlineAccounts = await _accountService.GetOfflineAccountsAsync(
                since: TimeSpan.FromHours(1)
            );
            
            // Run compressed simulation for each
            foreach (var account in offlineAccounts)
            {
                if (await _offlineService.ShouldRunOfflineSimulationAsync(account.Id))
                {
                    await _offlineService.RunOfflineSimulationAsync(account.Id, ...);
                }
            }
            
            await Task.Delay(TimeSpan.FromMinutes(30), stoppingToken);
        }
    }
}
```
